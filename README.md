# Connectif iOS SDK

[![SPM Compatible](https://img.shields.io/badge/SPM-compatible-brightgreen.svg)](https://github.com/swiftlang/swift-package-manager)
[![Platform](https://img.shields.io/badge/platform-iOS%2013%2B-lightgrey.svg)](https://developer.apple.com/ios/)
[![Latest Release](https://img.shields.io/github/v/release/connectif/Connectif-iOS-SDK)](https://github.com/connectif/Connectif-iOS-SDK/releases)

The official iOS SDK for [Connectif](https://www.connectif.ai), the customer engagement and marketing automation platform. It lets your app track contact behavior (page visits, product views, cart, purchases, custom events...) and receive Connectif push notifications, so you can power personalized journeys and campaigns from your Connectif account.

This repository hosts the package manifest and binary releases for distribution via Swift Package Manager. It does not contain the SDK's source code.

## Requirements

- iOS 13.0+
- Swift 5.3+
- A Connectif account and API Key

## Documentation

Setup and integration guides are available in the Connectif Help Center. For usage support, contact your Connectif account manager.

See [Releases](https://github.com/connectif/Connectif-iOS-SDK/releases) for the changelog and available versions.
